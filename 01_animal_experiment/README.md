# Animal experiment

`data/animal_outcomes.csv` is the single canonical animal-outcome table included in this package. Run `Rscript code/analyse_animal_outcomes.R` from this directory. Compact tables required to check the reported analysis are retained in `results_reference/`.

Raw flow-cytometry files, histopathology images, instrument exports, administrative spreadsheets, and Chinese narrative reports are not duplicated here. Their repository locations must be added to `../metadata/EXTERNAL_DATA_MANIFEST.tsv` before release.
