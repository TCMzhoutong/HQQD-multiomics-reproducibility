# Data sources and distribution plan

| Data class | Included in this package | Public-release route | Notes |
|---|---:|---|---|
| Curated animal phenotypes | Yes | GitHub/repository supplement | One canonical analysis table is included. |
| Flow-cytometry FCS files | No | Domain or institutional repository | Primary files are approximately 335 MB and are listed in the external-data manifest. |
| Shotgun metagenomic primary reads | No | — | Not available in the current study archive. |
| Processed shotgun metagenomic data and associated analysis files | Compact subset | OMIX | Accession OMIX020530; compact manuscript-aligned files are also included in this package. |
| Untargeted serum-metabolomics primary instrument files | No | MetaboLights, Metabolomics Workbench, OMIX, or another accepted metabolomics repository | Accession pending author deposition. |
| Processed metabolomics matrices and annotation tables | Yes | GitHub/repository supplement | Six implausible annotations are explicitly excluded from active analyses. |
| Public GWAS summary statistics | No | Original public repositories | Dataset identifiers, releases, and source publications are recorded in `EXTERNAL_DATA_MANIFEST.tsv`. |
| Compact MR intermediate and result tables | Yes | GitHub/repository supplement | Large reference panels and public summary-statistic files are not redistributed. |
| Public bulk and single-cell transcriptomic data | No | GEO/original repositories | Accession identifiers are documented in module metadata. |
| Docking inputs and compact score tables | Yes | GitHub/repository supplement | Vina executable is not redistributed. |
| MD trajectories and checkpoint files | No | General-purpose or institutional repository if required | Compact analysis summaries for the four retained systems are included. |
