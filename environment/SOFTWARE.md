# External software

The workflows call several programs that are not redistributed in this repository:

- R and Rscript;
- Python 3;
- PLINK for linkage-disequilibrium clumping;
- Cytoscape with the cytoNCA workflow for network centrality;
- AutoDock Vina for molecular docking;
- Open Babel for ligand conversion;
- PyMOL for structure inspection or rendering;
- GROMACS for molecular dynamics;
- gmx_MMPBSA for binding free-energy analysis;
- ACPYPE/AmberTools components used in ligand topology preparation;
- DSSP where required by secondary-structure analysis.

Exact software and package versions must be recovered from the analysis environment or author records and added before archival release. No executable binaries are bundled.
