# Author input required before public release

1. **Additional primary-data repository accessions.** Add accession numbers and persistent links for untargeted metabolomics primary data and flow-cytometry FCS files. Processed shotgun metagenomic data and associated analysis files are deposited in OMIX under accession `OMIX020530`.
2. **Metagenomic HQQD group identity.** Confirm which administered dose corresponds to samples `Z1`–`Z6`. The clean code uses the neutral label `HQQD` until this is resolved.
3. **Public GWAS identifiers and URLs.** Confirm the exact study/accession identifiers for every gut-microbiome, metabolite, pQTL, and bacterial-pneumonia outcome dataset used in the final MR analyses.
4. **Software versions.** Confirm versions for R, Python, Vina, GROMACS, gmx_MMPBSA, Cytoscape, cytoHubba, cytoNCA, MCODE, and any locally installed R/Python packages.
5. **CIBERSORT signature licensing.** Confirm whether the LM22 signature may be redistributed. It is not included in this draft package.
6. **Repository licence.** Select and add an author-approved code/data licence.
7. **Raw-data checksums.** Generate checksums after the external repository deposits are frozen.

Do not replace any of these items with invented accession numbers or approximate software versions.
