# Author input required before public release

1. **Additional primary-data repository accessions.** Add accession numbers and persistent links for untargeted metabolomics primary data and flow-cytometry FCS files. Processed shotgun metagenomic data and associated analysis files are deposited in OMIX under accession `OMIX020530`.
2. **Software versions.** Confirm versions for R, Python, Vina, GROMACS, gmx_MMPBSA, Cytoscape, cytoHubba, cytoNCA, MCODE, and any locally installed R/Python packages.
3. **CIBERSORT signature licensing.** Confirm whether the LM22 signature may be redistributed. It is not included in this draft package.
4. **Repository licence.** Select and add an author-approved code/data licence.
5. **Raw-data checksums.** Generate checksums after the external repository deposits are frozen.

Do not replace any of these items with invented accession numbers or approximate software versions.
