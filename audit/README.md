# Audit files

- `INCLUSION_EXCLUSION_AUDIT.md`: rationale for the curated package.
- `AUTHOR_INPUT_NEEDED.md`: information that must be supplied by the authors before release.
- `SOURCE_MODULE_MAP.tsv`: mapping from each curated module to its read-only source module.
- `FILE_MANIFEST_SHA256.tsv`: final package inventory, size, and SHA-256 checksum (excluding the manifest itself).
- `VALIDATION_REPORT.md`: automated consistency and portability checks.
