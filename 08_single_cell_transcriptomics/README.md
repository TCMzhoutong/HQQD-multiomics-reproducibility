# Single-cell transcriptomic analysis

Run the numbered scripts in `scripts/` using the settings in `config/`. The workflow analyses the public GSE263380 and GSE252663 datasets and scores the candidate target set across immune-cell and T-cell compartments.

Large raw GEO matrices are not bundled. Compact target inputs and manuscript-aligned output tables are retained; the source accessions are listed in `../metadata/EXTERNAL_DATA_MANIFEST.tsv`.
