# Shotgun metagenomics

Run the numbered R scripts from this directory. The bundled abundance matrices are the compact inputs used by the reported taxonomic and functional analyses; the scripts retain their original relative layout for reproducibility.

The complete processed shotgun metagenomic dataset and associated analysis files are deposited in OMIX under accession **OMIX020530**. `results_reference/` contains the compact manuscript-aligned outputs distributed with this GitHub package; external-data details are recorded in `../metadata/EXTERNAL_DATA_MANIFEST.tsv`.
